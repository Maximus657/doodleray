# Store Listing Draft — DoodleRay

Safe, certification-friendly wording. Do not improvise marketing claims.

## Short description

> DoodleRay is a Windows network client with full-device tunnel mode, browser
> proxy mode, and manual proxy tools. Full-device mode may require
> administrator permission on Windows.

## Long description (opening)

> DoodleRay includes optional full-device tunnel components for Windows,
> including a background service and virtual network adapter, to provide
> encrypted tunnel mode. Browser proxy mode and manual proxy mode are also
> available for scenarios where full-device routing is not required. Some
> Windows apps may not use proxy mode; full-device mode may require
> administrator permission to apply system routing, DNS, or proxy changes.

## Long description (continuation blocks — pick as needed)

> **Three honest modes.** "Whole computer" routes the entire device through an
> encrypted tunnel using a background service and virtual adapter. "Browsers"
> configures the system proxy for browsers and proxy-aware apps only.
> "Manual proxy" exposes a local SOCKS/HTTP proxy for advanced setups.

> **Clear status.** The dashboard shows the real connection state, including
> degraded or limited protection, and never presents partial protection as
> full protection.

> **Diagnostics you control.** If something breaks, preview and send a redacted
> diagnostic report. Automatic serious-error reports are optional and disabled
> until you explicitly enable them.

> **Your DoodleVPN account.** Sign in with the activation code issued for your
> DoodleVPN account; server configuration is delivered securely by the service.

## Metadata

- Category: Utilities & tools.
- In-app purchases: none in the package (external subscription disclosed).
- System requirements: Windows 10 22H2+ (x64); administrator permission for
  full-device mode.

## Phrases to AVOID anywhere in the listing (certification risk)

- "anonymous" / "anonymity guaranteed" / "no one can see you"
- "unblock everything" / "access any blocked site/service"
- "bypass restrictions/censorship/geo-blocks"
- "fastest VPN" / "best VPN" / "#1"
- "works with every app" (proxy modes explicitly do not)
- "military-grade encryption"
- "100% secure / unhackable"
- "completely free" (subscription is external)
- Any claim that the Store build auto-updates itself silently.

## Screenshot rules

- Real v6 UI only, real states (Protected / Limited shown honestly).
- No fabricated speeds, no fake country lists, no "unblocked" logos of
  third-party streaming brands.
